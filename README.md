# 📊 UNMSM 2026 · Dashboard de Análisis de Admisión

Proyecto de **análisis y visualización interactiva del proceso de admisión de la UNMSM 2026**, donde se transforman datos crudos en un **dashboard web moderno e interactivo**.

El proyecto combina **extracción de datos en Python, procesamiento de datasets y desarrollo de una interfaz web interactiva** para explorar estadísticas relevantes del proceso de admisión.

# 🚀 Pipeline del Proyecto

El flujo de trabajo del proyecto fue el siguiente:

### 1️⃣ Extracción de Datos

Se utilizó **Python** para recopilar y estructurar la información del proceso de admisión.

Procesos realizados:

* Recolección de datos
* Limpieza de información
* Transformación de estructuras
* Generación de datasets iniciales

---

### 2️⃣ Generación de Datasets

Los datos extraídos fueron almacenados en **datasets estructurados**, permitiendo su análisis posterior.

Se generaron datasets para:

* Facultades
* Escuelas profesionales
* Postulantes
* Vacantes
* Estadísticas generales

---

### 3️⃣ Dataset Consolidado

Posteriormente se creó un **dataset general unificado**, integrando toda la información procesada.

Este dataset permite:

* Análisis global del proceso de admisión
* Generación de métricas agregadas
* Integración con la visualización web

---

### 4️⃣ Desarrollo de la Web

Con el dataset final se desarrolló una **plataforma web interactiva** que permite visualizar los datos mediante gráficos y métricas dinámicas.

La interfaz permite:

* Explorar estadísticas del proceso de admisión
* Visualizar comparaciones entre facultades
* Analizar distribución de postulantes y vacantes
